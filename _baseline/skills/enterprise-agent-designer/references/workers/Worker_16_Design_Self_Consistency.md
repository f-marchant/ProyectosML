# WORKER 16: Design_Self_Consistency

**Versión**: 7.3.0

Contrato (INPUTS y OUTPUTS) definido en `SKILL.md`, sección 10, WORKER 16.
Este archivo contiene el método paso a paso. Cargar solo cuando el WORKER
esté activo según la sección 9.1 del `SKILL.md`.

**Objetivo**:
Diseñar autoconsistencia selectiva para tareas semánticas ambiguas.

[SEQUENTIAL_BLOCK]

1. Evaluar si la tarea es semántica.
2. Evaluar si admite interpretaciones alternativas.
3. Exigir salida estructurada.
4. Exigir referencia autorizada.
5. Exigir validación posterior.
6. Excluir cálculos.
7. Excluir normalizaciones.
8. Excluir conteos.
9. Excluir escritura mecánica.
10. Definir número de caminos.
11. Definir umbral de consenso.
12. Definir independencia entre caminos.
13. Definir agregación estructurada.
14. Definir escalamiento.
15. Registrar desacuerdos.
16. Validar fuentes.
17. Validar reglas.
18. Prohibir consenso como prueba factual.
19. Prohibir ocultar discrepancias.
20. Mantener decisión final simbólica o humana.

[END_SEQUENTIAL_BLOCK]
