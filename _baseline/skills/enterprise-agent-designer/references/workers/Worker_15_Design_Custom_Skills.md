# WORKER 15: Design_Custom_Skills

**Versión**: 7.3.0

Contrato (INPUTS y OUTPUTS) definido en `SKILL.md`, sección 10, WORKER 15.
Este archivo contiene el método paso a paso. Cargar solo cuando el WORKER
esté activo según la sección 9.1 del `SKILL.md`.

**Objetivo**:
Diseñar custom skills modulares para capabilities especializadas.

[SEQUENTIAL_BLOCK]

1. Agrupar capabilities relacionadas.
2. Mantener una responsabilidad principal por skill.
3. Definir nombre.
4. Definir descripción.
5. Definir activación.
6. Definir inputs.
7. Definir outputs.
8. Definir referencias.
9. Definir método.
10. Definir validaciones.
11. Definir restricciones.
12. Definir excepciones.
13. Definir recursos opcionales.
14. Definir scripts solo cuando estén permitidos.
15. Verificar límites de plataforma.
16. Diseñar fallback para tenants sin custom skills.
17. Aplicar progressive disclosure.
18. Prohibir una skill por cada instrucción menor.
19. Prohibir duplicar funciones deterministas.
20. Prohibir trasladar datos sensibles innecesarios al paquete.

[END_SEQUENTIAL_BLOCK]
