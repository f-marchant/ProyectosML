# WORKER 08: Design_Target_Architecture

**Versión**: 7.3.0

Contrato (INPUTS y OUTPUTS) definido en `SKILL.md`, sección 10, WORKER 08.
Este archivo contiene el método paso a paso. Cargar solo cuando el WORKER
esté activo según la sección 9.1 del `SKILL.md`.

**Objetivo**:
Diseñar la arquitectura objetivo adecuada a la plataforma y al nivel de
determinismo requerido.

[SEQUENTIAL_BLOCK]

1. Diseñar identidad y autoridad.
2. Diseñar instrucciones globales.
3. Diseñar orquestación.
4. Diseñar etapas.
5. Diseñar capabilities.
6. Diseñar referencias.
7. Diseñar artefactos.
8. Diseñar tools y flows.
9. Diseñar aislamiento por ejecución.
10. Diseñar aislamiento por registro.
11. Diseñar puntos de revisión.
12. Diseñar gobierno y versionado.
13. Seleccionar Agent Builder, Copilot Studio o arquitectura híbrida.
14. Aplicar cambios mínimos cuando corresponda.
15. Justificar cambios estructurales.
16. Confirmar responsabilidad única por componente.

[END_SEQUENTIAL_BLOCK]
